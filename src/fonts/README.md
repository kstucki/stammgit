# Local fonts

Source Serif 4: 400 and 600. Inter: 400, 500 and 600. Normal style, Latin subset
(including Western European accents), WOFF2. No other weights are shipped.
Downloaded 25 September 2026 from the Fontsource CDN:

- https://cdn.jsdelivr.net/fontsource/fonts/source-serif-4@latest/latin-400-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/source-serif-4@latest/latin-600-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/inter@latest/latin-400-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/inter@latest/latin-500-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/inter@latest/latin-600-normal.woff2

Both families are licensed under SIL OFL 1.1; the original licence/copyright
notices are alongside the font files. These checked-in files are the build input;
there are no runtime requests to these URLs. CSS lives in ../fonts.css.
